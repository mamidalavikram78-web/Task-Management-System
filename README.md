# Task Management System

A responsive frontend web application designed to help users create, organize, and track tasks efficiently in one place.

## 🚀 Live Demo

[View Live Website](https://mamidalavikram78-web.github.io/Task-Management-System/)

## 📌 Project Overview

The Task Management System is a frontend web application that provides a simple and user-friendly workspace for managing daily tasks.

Users can create tasks with details such as title, description, due date, priority, and category. The system allows users to manage task status, search and filter tasks, track completion progress, and store task data using the browser's LocalStorage.

## ✨ Key Features

- 📊 Interactive dashboard with task statistics
- ➕ Add new tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- ✅ Mark tasks as completed or uncompleted
- ⭐ Mark important tasks
- 🔍 Search tasks
- 🔽 Filter tasks by status, priority, and category
- 📅 Sort tasks by due date
- 📈 Track task completion progress
- 🌙 Dark mode
- 📱 Responsive design
- 📥 JSON import and export
- 💾 LocalStorage persistence

## 🛠️ Technologies Used

- **HTML5** – Semantic structure, forms, and page components
- **CSS3** – Responsive layouts, styling, themes, Grid and Flexbox
- **JavaScript (ES6+)** – DOM manipulation, event handling, CRUD operations, search, filtering, sorting, and dashboard updates
- **LocalStorage API** – Persistent browser-based task storage

**No external dependencies are required.**

## ⚙️ How to Run

### Option 1: Live Website

Open the live website using the link provided above.

### Option 2: Run Locally

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Start creating and managing tasks.
